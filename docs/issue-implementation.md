# 要望をIssueに追加する

v1.3.8では画面上部、ヘルプ・設定の左側の「要望」からGitHub Issueを作成できます。実装・ビルドの依頼ボタンは削除しました。OpenAI APIキーやActions書き込み権限は不要です。

1. 「要望」を開き、GitHubトークン、タイトル、再現手順、期待する動作を入力します。
2. 「GitHubトークンを保存する」を有効にして「Issueを追加」を押すと、送信前にトークンを保存します。次回画面を開いたときは自動入力されます。保存を無効にした場合は今回入力したトークンを保存しません（既存の保存データは削除しません）。
3. 作成後は「Issue・進捗」で作成したIssueを確認できます。通信が切れた場合、作成済みの可能性があります。重複を避けるためIssue一覧を確認してから再送してください。
4. 保存を解除するには「保存済みトークンを削除」を押します。保存データと入力欄が消え、保存チェックも外れます。GitHub側のトークン自体を失効する場合はGitHubで操作してください。

トークンは `%LOCALAPPDATA%\Footprint\GitHubSettings.json` にWindows DPAPIで暗号化して保存します。同じWindowsユーザーでのみ復号できます。別PC・別ユーザーに設定ファイルを移した場合はトークンを入力し直してください。保存ファイルには平文のトークンを書きません。暗号化は同じWindowsユーザーとして動く他のプログラムからのアクセスを防ぐものではありません。

読み込みに失敗した場合は案内を表示し、保存ファイルを保持します。再入力して保存するか、保存済みデータを削除できます。保存に失敗した場合はIssueを送信せず、エラーを表示します。送信に失敗しても保存したトークンは残ります。

## GitHubトークンの作成

GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokensで、対象リポジトリ `posita33/Footprint` を指定し、Repository permissions → Issues: Read and writeを許可します。期限切れの場合は新しいトークンを入力して保存してください。

トークンがなくても「ブラウザーでIssue作成」からGitHubにログインして作成できます。本文はURL長を抑えるため先頭4,000文字まで引き継ぐので、送信前に内容を確認してください。

要望は公開Issueになります。個人情報や秘密は含めないでください。コマンド・履歴・出力・トークンは自動添付しません。正式リリースの確認と更新は従来どおりメイン画面下部の「最新版に更新」を使います。
