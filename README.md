# Footprint

Visual Studio / C# WPF で、画面から実行したコマンドを記録・検索・再利用する Windows 用ツールです。

## 開発・起動

アプリアイコンの元デザインは `src/Footprint/Assets/Footprint.svg` です。PythonとPillowで `python src/Footprint/Assets/build_icon.py` を実行すると、同じデザインのEXE・タスクバー用複数サイズICOを再生成できます（Pillowは `pip install Pillow` でインストール）。

- Windows 10 / 11
- Visual Studio 2022 17.8 以降の「.NET デスクトップ開発」ワークロードと .NET 8 SDK
- `Footprint.sln` を開き、`Footprint` をスタートアッププロジェクトにして F5 で起動
- CLI: `dotnet build Footprint.sln`、`dotnet run --project src/Footprint`
- コア機能の検証: `dotnet run --project tests/Footprint.Core.SmokeTests`

## 公開用リリース

`v1.0.0` のような `v` で始まるタグを GitHub へ push すると、Windows x64 向けの自己完結型 Release ビルドが `Footprint-win-x64.zip` として GitHub Release に添付されます。ZIP を展開して `Footprint.exe` を起動してください。.NET の別途インストールは不要です。

GitHub Actions の「Create release package」を手動実行した場合は、同じ ZIP をワークフローの成果物からダウンロードできます。公開する場合はタグを push してください。

## 使い方

下部の履歴ボタンまたは `Ctrl + Space` で履歴・検索・バックアップを折りたためます。空いた縦幅を出力欄へ割り当て、再表示時には折りたたむ前の高さへ戻します。`Ctrl + F` は履歴を展開して検索へ移動します。実行中でも開閉でき、履歴や検索条件は保持します。

右上の「ヘルプ」または `F1` で、ショートカット一覧・使い方・保存先をアプリ内で確認できます。

右上の「設定」ではライト／ダークのテーマと、コマンド・出力の文字サイズ（12～24）を変更できます。「保存」で全ウィンドウへ反映し、次回起動時にも適用します。「キャンセル」では変更しません。「標準に戻す」で初期値を選択し、「保存」で反映できます。設定は `%LOCALAPPDATA%\Footprint\Settings.json` に保存します。入力欄・ボタン・履歴表は読みやすい標準配色を維持します。

1. コマンドプロンプトまたは Windows PowerShell を選択します。
2. 作業フォルダーとコマンドを入力して「実行」を押します。エクスプローラーからフォルダーを画面へドラッグ＆ドロップして、作業フォルダーを設定することもできます（単一フォルダーのみ。実行中は変更不可）。
3. 出力・終了コードを確認します。「停止」で実行中のプロセスツリーを終了できます。
   「出力をコピー」で表示中の出力をすべてクリップボードへコピーできます。履歴を選択して表示した結果もコピーできます。出力が空の場合はクリップボードを変更しません。
4. 履歴を選択して「入力に戻す」またはダブルクリックで再利用します。再実行には「実行」を押してください。
5. 履歴を選んで「☆ お気に入り」を押すと、いつでも再利用したいコマンドを記録できます。「お気に入りのみ」で絞り込めます。
6. 検索欄でコマンド、作業フォルダー、シェルを絞り込めます。「コピー」でコマンドをクリップボードへコピーできます。
7. 「お気に入り以外を削除」で不要な履歴をまとめて削除できます。削除前の状態はその日のバックアップへ保存されます。
8. 起動時に履歴を実行日別にバックアップします。通常バックアップには画面の実行日時の日付が一致する履歴だけを追加します（お気に入りも同じ条件）。同じIDは最新の内容で更新し、削除済みのバックアップ履歴は保持します。お気に入り専用バックアップには実行日に関係なくすべてのお気に入りを保存します。「今日のバックアップを保存」で両方を更新できます。種別「履歴／お気に入り」と日付を選んで復元します。履歴復元は現在の履歴を置き換え、お気に入り復元は通常履歴を保持して星印を置き換え、足りないお気に入り履歴を追加します。削除・復元前にも両方を保存します。
9. 「＋ タブ」でフォルダーごとの作業タブを追加できます。タブをウィンドウ外へドラッグすると別ウィンドウになり、「元のウィンドウにまとめる」で切り離したタブを戻せます。履歴・お気に入り・バックアップはすべてのタブと別ウィンドウで共有されます。
10. 終了時にタブの状態を保存します。次回起動時に「元のウィンドウにまとめる」の右側に表示される「復元」を押すと、作業フォルダー・シェル・コマンド・出力・選択中のタブを復元します。コマンドは再実行しません。「復元」または「＋」を押すと復元ボタンは非表示になります。切り離したウィンドウのタブは、元のウィンドウへまとめて復元します。

タブの状態は `%LOCALAPPDATA%\Footprint\Session.json` に保存します。未実行の入力コマンドも保存対象です。

履歴は `%LOCALAPPDATA%\Footprint\History` に実行ごとの JSON として保存します。実行日別バックアップは `History\Backups\yyyy-MM-dd.json`、お気に入り専用バックアップは保存日の `History\FavoriteBackups\yyyy-MM-dd.json` です。既存バックアップは復元可能で、通常バックアップを更新すると日付の異なる履歴は除外されます。壊れたバックアップは上書きせずエラーを表示します。壊れた履歴ファイルは保持したまま読み飛ばし、件数を通知します。実行前に履歴を保存できない場合はコマンドを実行しません。強制終了などで結果を保存できなかった履歴は「結果未確定」と表示します。

コマンドは現在の Windows ユーザー権限で実際に実行されます。履歴にはコマンドと出力が平文で残るため、パスワードやトークンを入力しないでください。

各実行は独立したシェルです。`cd` や変数は次の実行へ引き継ぎません。必要な処理は同じ入力欄にまとめてください。シェルのプロファイルは読み込まず、対話入力・端末画面を必要とするコマンドには対応しません。入力ストリームは閉じています。出力は標準出力・標準エラーを混在表示し、先頭約 100,000 文字まで保存します。履歴の自動削除は行いません。

## Windows での動作確認

タブの追加は `Ctrl + T`、現在のタブを閉じる操作は `Ctrl + W`、次／前のタブへの移動は `Ctrl + Tab` / `Ctrl + Shift + Tab` です。最後のタブは閉じずに残します。実行中のタブ操作は無効です。`Ctrl + F` で履歴検索欄へ移動できます。コマンド欄の Enter は改行、`Shift + Enter` は実行です。

- CMD: `echo こんにちは` と `tree` を実行し、日本語を含む出力、終了コード 0、再起動後の履歴を確認
- PowerShell: `Write-Output 'こんにちは'; exit 7` を実行し、日本語の出力と終了コード 7 を確認
- `Get-Location` で指定した作業フォルダーを確認
- エクスプローラーから空白や日本語を含むフォルダーを画面・入力欄へドロップし、作業フォルダーだけが更新され、`Get-Location` でそのパスが表示されることを確認
- ファイル・複数フォルダー・実行中のドロップで作業フォルダーとコマンド欄が変更されないことを確認
- `Start-Sleep -Seconds 30` を実行して停止し、「停止」履歴が残ることを確認
- 存在しないコマンドで失敗時の出力・終了コードを確認
- 履歴の検索・コピー・入力への復元を確認
- 履歴をお気に入りに追加・解除し、再起動後も星印と「お気に入りのみ」の絞り込みが保持されることを確認
- お気に入り以外を削除し、お気に入りだけが残ること、当日のバックアップから削除前の履歴を復元できることを確認
- 日付の異なるバックアップを選択して復元し、現在の履歴が置き換わり、復元前の状態が当日のバックアップに保存されることを確認
- タブを追加・削除し、フォルダー、シェル、コマンド、出力がタブごとに保持されることを確認
- タブをウィンドウ外へドラッグして切り離し、各ウィンドウで作成した履歴が共有され、「元のウィンドウにまとめる」で作業タブが戻ることを確認

WPF の画面と Windows シェルの確認は Windows 上で行ってください。
